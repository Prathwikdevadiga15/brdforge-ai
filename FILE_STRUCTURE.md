## Languages and technologies

| Area | Languages / technology |
|---|---|
| UI and server application | TypeScript, TSX, React 19, Next.js App Router |
| Styling | CSS, Tailwind CSS v4 |
| Request validation | TypeScript, Zod |
| Persistence | PostgreSQL, Prisma Schema Language, SQL migrations |
| Demo seed | JavaScript ES modules |
| AI extraction | OpenAI-compatible chat completions with JSON Schema; labeled heuristic fallback |
| API contracts | HTTP, JSON, multipart form data |
| Tooling/configuration | JSON, MJS, TOML, YAML (Docker Compose) |

There is no separate Python/FastAPI backend in this repository. Backend APIs are Next.js Route Handlers running on Node.js.
